# XELYON CLI - Homebrew Tap

[XELYON CLI](https://github.com/susugadx/xelyon-cli)の公式Homebrew Tapです。

## 📦 インストール方法

```bash
brew install susugadx/tap/xelyon
```

または

```bash
brew tap susugadx/tap
brew install xelyon
```

## 🔄 アップデート方法

```bash
brew update
brew upgrade xelyon
```

## 🗑️ アンインストール方法

```bash
brew uninstall xelyon
```

Tapも削除する場合:

```bash
brew untap susugadx/tap
```

## 📝 XELYON CLIについて

XELYON CLIは高速・軽量なLLMコーディングアシスタントです。

### 主な機能

- 🌐 **6種類のLLMプロバイダー対応**: DeepSeek, OpenAI, Gemini, Claude, Ollama, Groq
- 🤖 **複数のAIモデル対応**: 各プロバイダーで複数モデルを選択可能
- 💬 **対話型エージェント**: ツールを使って実際にコード編集・Git操作を実行
- 🔍 **Web検索機能**: Serper APIを使ったリアルタイムWeb検索
- 📂 **会話履歴管理**: セッションをJSONL形式で保存・復元
- ↩️ **Undo機能**: ファイル変更の取り消し（最大10件）

### サポート環境

- **macOS**: Intel (amd64), Apple Silicon (arm64)
- **Linux**: amd64, arm64
- **Windows**: amd64
